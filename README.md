# Курсовая работа на тему "Консольное приложение на языке Си - игра "Быки и Коровы""
## Довольно простая игра на отгадывание чисел. Происходит в диалоговом режиме. Пользователь вводит данные, отвечая на вопросы машины.
<img width="575" height="197" alt="image" src="https://github.com/user-attachments/assets/90c62a2f-f203-42f2-92c0-6a5eed0be1a4" />

## В коде генерится случайное число заданной длины в виде отдельной функции, а также реализована проверка вводимых данных на соответствие (числа вне диапазона, символы, абракадабра...).
<img width="502" height="294" alt="image" src="https://github.com/user-attachments/assets/08dbade5-80e0-431f-9e45-820d11e464cd" />

## Сам игровой процесс реализован в виде цикла. Чтобы была возможность выйти из игры, каждый следующий проход предваряется впросом о продолжении. При выходе приложение сообщает о количестве проделанных попыток и раскрывает пользователю загаданное число.
<img width="462" height="144" alt="image" src="https://github.com/user-attachments/assets/27d70ca6-2655-4194-9c8e-bf71c35d5e69" />

## При отгадывании числа цикл завершается автоматически. Далее всё аналогично принудительному завершению игры.
<img width="472" height="173" alt="image" src="https://github.com/user-attachments/assets/b192743f-333e-43ee-b798-ce766052dd4e" />

## В репозитории содержатся файлы проекта, сам код main.c, а так же исполняемый бинарник в разделе релизов. Его можно запустить на машине под управлением ОС Windows.
